David M. Beazley의 파이써닉한 파이썬을 익히는 간결한 안내서 (원제 Python Distilled, 인사이트, 2022)를 공부한 기록

## 소개

- [AI 프로젝트](https://github.com/corkang/ai-from-scratch)를 본격적으로 시작하기 전, 파이썬 문법을 복습한다.
- Python Distilled 책을 주교재로 보며, LLM을 활용해 설계한 [실습 프로젝트](project.md)를 수행한다.
- 초기 코드 작성은 AI의 도움 없이 진행하고, 검증 시에만 AI를 활용한다.

## 학습 방법

1. 책의 해당 섹션 읽기
2. 예제 실행
3. project.md의 task 기반 테스트 작성
4. 코드 작성 및 테스트 실행

## 출처와 저작권

이 저장소에는 David M. Beazley의 *Python Distilled* (Pearson, 2022)를 공부하며 작성한 정리 노트와 실습 코드가 포함됩니다.

책의 본문, 이미지, PDF 또는 공식 예제 코드를 재배포하지 않습니다. 외부 자료를 사용할 때는 해당 자료의 출처와 라이선스를 별도로 표시합니다.
